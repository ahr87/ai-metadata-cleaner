Please note

This tool removes metadata and provenance information stored inside the file, where technically possible.

Removing metadata does not guarantee that Instagram, Facebook, TikTok, or another platform will stop identifying an image as AI-generated. Platforms may also analyse the image itself (for example, invisible watermarks or visual detection), which no metadata cleaner can change. This tool does not bypass AI detection.
